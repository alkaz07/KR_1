2) Аналитически (не запуская код) определить, что выведет фрагмент программы
int i=0, N=7, x= 2;
//i=5;
while(i<=N)
{
	++i;                           // 1    2  3    4   5   6   7   8
	x *= 2;                        // 4    8   16  32  64  128 256 512
}
System.out.println("i="+i+" x="+x);     // i = 8 x = 512

3) Аналитически (не запуская код) определить, что выведет фрагмент программы

for(i=4; i<N; i++);                         // ; тело цикла нет

4) Какую строку выведет следующая программа
public class Main {
   public static void main(String[] args) {
        int k = 5;
        f1(k);
        System.out.println(""+k);       //  5, так как мы выводим переменную, а не результат метода
    }

    public static void f1(int x)
    {
        x += x--;
    }
}
