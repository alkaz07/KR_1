1.	Какая строчка нижеприведенного кода вызовет ошибку и почему?
Какие исправления следует внести, чтоб код заработал?
        double x, y=10; 						//не указано значение x
        System.out.println(x+y);
        System.out.println("ы"+x+y); 			// приведение типов
        int z = 25-y;                           // приведение типов int и double
        System.out.println(x+' '+y+' '+z);

Ответ:
Необходимо инициализировать x и привести типы к одному значению

2.	Аналитически (не запуская код) определить, что выведет фрагмент программы

//i=5;
while(i<=N)
{
	++i;
	x *= 2;
}
System.out.println("i="+i+" x="+x);

Ответ:

3.	Аналитически (не запуская код) определить, что выведет фрагмент программы
int i, N=7, x=2;
for(i=4; i<N; i++);                 //; в конце for не запустит тело цикла
	x*=2;
System.out.println("i="+i+" x="+x);
