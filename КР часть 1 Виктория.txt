1)Какая строчка нижеприведенного кода вызовет ошибку и почему?
  Какие исправления следует внести, чтоб код заработал?
		double x, y=10;
        	System.out.println(x+y);
        	System.out.println("ы"+x+y);
        	int z = 25-y;
        	System.out.println(x+' '+y+' '+z);
Ответ:
не задано значение x - нужно указать, например 0
y — double, z — int - нужно приведение int z = (int) (25 - y);
System.out.println(x+' '+y+' '+z) - ' ' число 32, а не пробел- заменить на "" System.out.println(x + " " + y + " " + z);

//i=5;
while(i<=N)
{
	++i;
	x *= 2;
}
System.out.println("i="+i+" x="+x);

Ответ:

3) Аналитически (не запуская код) определить, что выведет фрагмент программы
int i, N=7, x=2;
for(i=4; i<N; i++);
	x*=2;
System.out.println("i="+i+" x="+x);

Ответ:
